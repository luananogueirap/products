## Funcionalidades principais:
- Listagem de produtos em /products.
- Cadastro de produtos em /products/create.
  
- Armazenamento de:
  - Nome
  - Imagem por URL
  - Preço
  - Descrição
    
- Visualização detalhada de um produto em:
/products/:id

- Edição de produtos em:
/products/edit/:id

- Exclusão de produtos através do formulário na página de detalhes:
POST /products/remove/:id

- Layout responsivo inspirado no design enviado, com:
  - Navbar personalizada.
  - Logo em SVG.
  - Cards de produtos.
  - Imagens dos produtos.
  - Página de detalhes.
  - Formulários estilizados.
